# אני פרווה

אפליקציית אנדרואיד בעברית לניהול זמן המתנה אישי בין בשרי לחלבי ובין חלבי לבשרי. הנתונים נשמרים במכשיר בלבד.

## גרסאות
- **2.0.0 — אני פרווה 2.0:** טיימרים מרובים עם שמות, שעת סיום, התחלה בדיעבד, שמות קבועים וזמני המתנה אישיים, וידג'ט ומסך הסבר.
- **1.1:** עיצוב מחודש, מסך טיימר ייעודי, התאמות בהגדרות וסמל אפליקציה חדש.
- **גרסאות build קודמות:** נשארות זמינות בעמוד Releases.

## בנייה והתקנה
- מזהה חבילה: `il.co.aniparve`.
- תאימות: Android 5.0 ומעלה (minSdk 21).
- GitHub Actions בונה APK, מריץ lint ומעלה Artifact.
- גרסה 2.0.0 מופצת ב-tag `v2.0.0` עם הקובץ `ani-parve-v2.0.0.apk`.
