# אני פרווה

אפליקציית אנדרואיד בעברית לניהול זמן המתנה אישי בין בשרי לחלבי ובין חלבי לבשרי.

## בנייה והתקנה
1. היכנסו ללשונית **Actions** ובחרו את ריצת **Build Android APK**.
2. לאחר הצלחה, הורידו את `ani-parve.apk` מתוך ה-Artifacts או מעמוד Releases.
3. העבירו את הקובץ לטלפון והתקינו אותו. ייתכן שתצטרכו לאשר התקנה ממקור זה בהגדרות Android.

## הערות
- הנתונים נשמרים מקומית במכשיר; אין שרת, חשבון משתמש או הרשאת אינטרנט.
- מומלץ לאפשר התראות ולבדוק הגדרות סוללה של המכשיר כדי לצמצם עיכובים.
- חתימת ה-Release היא חתימת debug של Gradle, ולכן זו גרסת התקנה לבדיקה ולא חתימת הפצה לחנות.

## מצב בנייה
GitHub Actions בונה APK בכל push וגם בהפעלה ידנית (workflow_dispatch). הקובץ מצורף ל-Artifacts ול-Releases כאשר הבנייה והפרסום מסתיימים בהצלחה.
